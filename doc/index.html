PULSERELAY · ANDROID PRODUCT BLUEPRINT

Private wallet alerts, delivered with intention.

A premium Android companion that recognizes Bangladesh bKash, Nagad, and Rocket transaction SMS messages on-device, removes sensitive data, and posts only safe events to an owned Telegram channel through a bot.

1. Product boundary

01

Approved sources only

Start with a strict allow-list for bKash, Nagad, and Rocket sender IDs. Unknown senders and arbitrary messages stay on the phone.

02

Safe by default

OTP, PIN, verification-code content, phone numbers, and long identifier sequences are blocked or redacted before any network request.

03

Owned destination

The user configures a bot they control and a private channel where the bot has posting permission. No shared relay service is required.

!

Important Android and privacy note

These are financial notifications. Use the app only on a phone and Telegram channel you own or have explicit permission to monitor. Android/Google Play SMS permissions are restricted; a Play release may require the app to qualify as a default SMS handler or another permitted exception. Most Bangladesh wallet alerts arrive as SMS, not MMS, so the implementation uses the SMS broadcast path instead of scraping arbitrary MMS parts.

2. Premium UI direction

Visual language

  • Deep navy canvas with elevated slate surfaces.
  • Mint green for trust, active state, and successful delivery.
  • Soft blue for Telegram actions; amber for attention.
  • Large rounded cards, restrained gradients, generous spacing, and readable type.

Experience principles

  • One clear action per screen: enable, pause, configure, or review.
  • Never show raw SMS text in the activity feed.
  • Show exactly what the filter will do before the user enables it.
  • Make relay health visible without making the screen noisy.

Dashboard

Connection health, live/pause control, matched today, items needing review, recent redacted activity, and a privacy reassurance.

Rules

Three provider cards with switches, local-matching explanation, and the redaction control. The visual state maps to encrypted local settings.

Settings

Masked bot-token entry, channel ID, encrypted save, SMS access explanation, and delivery-notification controls.

Runtime components

  • Compose UI: dashboard, rules, and settings.
  • MessageFilter: pure Kotlin allow-list and redaction logic.
  • SmsReceiver: accepts incoming SMS only.
  • RelayWorker: network constraint, retry, and delivery.
  • LocalConfigStore: Android encrypted preferences for token, destination, rules, and enabled state.
  • TelegramBotClient: minimal sendMessage client with no credential logging.

Recommended production additions

  • Bounded redacted history using Room or SQLCipher.
  • Notification channel and Android 13 notification permission flow.
  • Bot permission validation and a safe test-send flow.
  • Exponential backoff with rate-limit-aware handling.
  • Pause, delete history, clear credentials, and export controls.
  • Device reboot and battery-optimization education.

5. Telegram setup checklist

Bot

  1. Create a bot with BotFather.
  2. Copy the token into PulseRelay only; never commit it.
  3. Keep the bot limited to the destination channel.

Channel

  1. Create or select a private Telegram channel.
  2. Add the bot as an administrator with permission to post.
  3. Enter the channel chat ID and use a safe test message first.

6. Android support and release policy

Supported baseline

Minimum Android 10 / API 29. Target SDK 35 (Android 15). Android 10–15 can be compiled and tested with the corresponding installed SDK platforms.

Forward compatibility

Android 16–17 can be re-tested as official SDKs become available. The app cannot use Android 17-only APIs until an official compile SDK is installed.

APK

Release after every change

Each change should increment the version, run the relevant checks, build an unsigned release APK, commit and push the source, then publish a GitHub release containing the APK. A private signing keystore is required for a production install and must stay outside GitHub.
